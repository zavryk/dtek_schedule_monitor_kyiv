# 🪫 DTEK schedule monitor

Моніторинг **екстрених/аварійних** відключень на сайтах ДТЕК КЕМ (Київ) і ДТЕК КРЕМ (область)
для кількох адрес одним запуском, зі сповіщеннями в Telegram.

Основа — [mr-devboy/dtek-monitor](https://github.com/mr-devboy/dtek-monitor) (MIT).

## Як працює

- Один запуск GitHub Actions: Chromium стартує один раз, сторінка кожного сайту відкривається один раз,
  кожна вулиця запитується один раз — далі перевіряються всі адреси з `TARGETS`.
- Повідомлення шлеться, лише коли відключення екстрене/аварійне і його період змінився.
- Стан (який період куди вже відправлено) — `artifacts/state.json`, комітиться після кожного запуску.
- 00:00–06:29 за Києвом повідомлення приходять без звуку.

## Secrets

| Secret               | Опис                     |
| -------------------- | ------------------------ |
| `TELEGRAM_BOT_TOKEN` | Токен бота від BotFather |
| `TARGETS`            | JSON-масив адрес (нижче) |

```json
[
  { "site": "kem", "street": "вул. Приклад", "house": "1", "chats": ["-1001234567890"] },
  {
    "site": "krem",
    "city": "м. Кагарлик",
    "street": "вул. Приклад",
    "house": "2А",
    "showStreet": true,
    "chats": ["-1001111111111", { "id": "-1002222222222", "thread": "15" }]
  }
]
```

| Поле         | Опис                                                         |
| ------------ | ------------------------------------------------------------ |
| `site`       | `kem` — Київ, `krem` — Київська область                      |
| `city`       | Населений пункт як на сайті (для `krem`)                     |
| `street`     | Вулиця як на сайті                                           |
| `house`      | Номер будинку як на сайті                                    |
| `showStreet` | Показувати вулицю в повідомленні                             |
| `chats`      | ID чатів; `{ "id", "thread" }` — для гілки (topic) у групі   |

## Запуск

Workflow запускається через `workflow_dispatch` (зовнішній тригер раз на 10 хв).
Для переходу зі старих репозиторіїв перший раз запустіть з `dry_run: true` —
поточні відключення запишуться у стан без відправки, щоб не дублювати повідомлення.

Локально:

```sh
npm ci && npx playwright install chromium
cp .env.example .env   # заповнити
npm start
```
